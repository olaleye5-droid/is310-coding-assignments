# Source and Style
## Digital Collection
I chose Wikimedia Commons because it is a large digital collection of images and other media. I am interested in using it to explore discrimination and representation in basketball. Wikimedia Commons has many basketball-related images, including images of African American basketball players and teams.

## Web Technologies
Wikimedia Commons uses HTML, CSS, and JavaScript to build and style its web pages. The MediaWiki software used by Wikimedia projects includes files for JavaScript, CSS, and other web technologies. The website also uses additional files and resources to support its features and design.

## Who Built It?
Wikimedia Commons is part of the Wikimedia projects and is supported by the Wikimedia community. The MediaWiki software is developed and maintained by many contributors. The GitHub repository has a large number of commits and contributors, showing that many people have worked on the software.

## Connection to My Project
Wikimedia Commons is useful for my project because it has images that can help me study discrimination and representation in basketball. I can use these images to look at how African American players, teams, and basketball communities have been represented over time.
