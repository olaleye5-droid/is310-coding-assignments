# AI Chat Log — WNBA Gender Inequality Data Curation

## Project Background

My project focuses on documenting gender inequality in the Women's National Basketball Association (WNBA). I chose this topic because I wanted to examine how discrimination, compensation, and working conditions affect women's basketball. My instructor's feedback helped me narrow the scope and think more carefully about the evidence needed for each record.

## How I Used AI

I used ChatGPT as a learning and troubleshooting resource while developing my project. I worked through the steps in VS Code on my Windows laptop and used AI guidance when I needed help understanding commands, organizing files, and correcting my implementation.

### 1. Setting Up the Python Environment

I received guidance on creating and activating a Python virtual environment, installing the Rich library, and organizing the files in my project folder. I ran the commands in my terminal and checked that the environment and required package worked.

### 2. Developing the Python Interface

I used AI assistance to help structure a command-line data-entry program using Python and Rich. I saved the code in `cli_data_entry.py`, ran the program, and tested entering and confirming a research record. I checked that the program saved the record in `basketball_data.json`.

### 3. Developing the HTML Interface

I used AI assistance to create and revise an HTML form for collecting the same information through a browser. I opened `index.html`, refreshed the webpage after changes, and tested the form by entering, reviewing, and confirming records. I also tested downloading the confirmed records as a JSON file.

### 4. Choosing and Refining the Research Topic

I selected gender inequality in the WNBA as my focus after considering my instructor's feedback. I worked on narrowing the project from a broad topic about discrimination in basketball to documented events and public accounts involving gender, compensation, and working conditions.

I also used AI assistance to identify relevant sources and organize information into fields such as event title, date, institution, source, documented response, and uncertainty. I learned that a reported allegation should not automatically be treated as proof of discrimination.

### 5. Testing and Troubleshooting

I tested both interfaces and checked that records could be saved in JSON format. I also verified that my project contained the Python script, HTML interface, JSON data file, README, and requirements file. AI guidance helped me work through these steps one at a time.

## My Contributions and Decisions

I selected the research topic, used my instructor's feedback to narrow the scope, entered and reviewed records, tested the interfaces, and organized the project files. I made decisions about what information each record should preserve and why source context and uncertainty matter.

ChatGPT assisted with code examples, explanations, documentation drafts, and troubleshooting. I reviewed the suggestions and carried out the setup, file editing, data entry, and testing steps on my computer.

## Reflection

This process helped me understand that data curation involves more than collecting information. The fields used to organize a dataset influence what researchers can see and what context might be lost. Keeping sources, institutional responses, and uncertainty visible is especially important when documenting allegations of discrimination.
